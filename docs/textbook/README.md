# ポートフォリオで学ぶ Web 制作 — 目次

このポートフォリオを作り直しながら、HTML・CSS・TypeScript・WebGL・Three.js を復習するための教科書です。
各章で実際にサイトのコードを書き、最後に小さな演習を置いています。

## 方針

- **軽く作る**：最初に読み込むのは HTML・CSS・小さな TS と、素の WebGL で描くシェーダー背景だけにする。Three.js（最小構成でも gzip で約133KB）は、3D の章で「画面に入ったときだけ」読み込む
- **TypeScript で書く**：ブラウザは TS を直接実行できないので、Vite で JS に変換して公開する
- **内容はデータとして分ける**：作品・スキル・経歴は JSON に書き、HTML はそこから作る。更新は JSON を書き換えるだけで済むようにする
