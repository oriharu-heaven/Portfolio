# 第0章　この教科書の使い方と全体像

## 0.1 進め方

1. 章ごとに、私（Claude）がサイトのコードを書き、この `docs/textbook/` に解説を書く
2. あなたは解説を読みながらコードを読み、手元で動かす
3. 章末の「演習」を自分で解く。分からなければ、そのまま質問してください
4. 納得したら次の章へ

解説では「何を書いたか」より **「なぜそう書くのか」「他にどんな書き方があり、なぜ選ばなかったか」** を重視します。

## 0.2 作るもの

```
┌────────────────────────────────────────┐
│  背景：Warp Shader（素の WebGL）        │ ← 最初から表示。数KB
│  ┌──────────────────────────────────┐  │
│  │ 名前・自己紹介                     │  │
│  │ 作品（JSON から生成）              │  │
│  │ スキル（JSON から生成）            │  │
│  │ 経歴（JSON から生成）              │  │
│  │ Playground（Three.js）             │  │ ← 画面に入ったら読み込む
│  │ 連絡先                             │  │
│  └──────────────────────────────────┘  │
└────────────────────────────────────────┘
```

背景のシェーダーは、自作の [Warp Shader Lab](https://github.com/oriharu-heaven/warp-shader-lab) のフラグメントシェーダー（ドメインワーピング＋網点）を使います。

## 0.3 なぜこの構成にしたか（他の案との比較）

| 決めたこと | 選んだ案 | 選ばなかった案と理由 |
| --- | --- | --- |
| 言語 | TypeScript + Vite | JS + JSDoc で型チェックだけする案もあった。ビルドが要らない利点はあるが、TS の文法自体を練習できない |
| 背景の描画 | 素の WebGL | 背景も Three.js にすると書き方は統一できるが、最初の読み込みが約133KB（gzip）増える。今のサイト全体（HTML+CSS+JS）は gzip で約13KB |
| 3D | Three.js を後から読み込む | 素の WebGL だけで 3D を書くのは学びは深いが、行列計算などを全部自分で書くことになり、遊ぶ前に疲れる |
| 内容の管理 | リポジトリ内の JSON | Supabase や Google スプレッドシートから読む案もあった。main へのコミットは不要になるが、表示のたびに通信が発生し、外部サービスが止まると中身が出ない |

※ 133KB は、Three.js 0.187.0 で「レンダラー・シーン・カメラ・メッシュ1つ・ShaderMaterial」だけを使う最小コードを esbuild でまとめて計測した値です。実際に使う機能が増えれば大きくなります。
