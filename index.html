サークル練習管理アプリ

約150名のダンスサークルの練習日程・空き部屋の申請・出欠・鍵の受け渡しをまとめたWebアプリ。

Webアプリ2026.9 –

  • Next.js
  • TypeScript
  • Supabase
  • Vercel
詳しく見る
課題
練習室の時間割はExcelを画像にしてLINEで共有。出欠は個別確認で、見落としが起きていた。
機能
練習室ごとの時間割、10分単位の空き部屋申請（重複はDB制約で防止）、出欠回答、鍵の所在共有、カレンダー連携、役職ごとの権限。
結果
運用開始から約2か月で、ほぼ全員が週3〜4日利用。出欠確認の手間がほぼなくなった。
役割
企画・仕様・設計から運用・改善まで自分で担当。コーディングにはAIエージェント（Claude Code）を活用。

ミガキ殿

歯みがきの2分間で気分や体調を記録するサービス。歯ブラシのちょんまげをした「おとのさま」が問いかけ、ダイヤルで答える。

Webアプリ・デバイス2026.9 –

  • TypeScript
  • React
  • IndexedDB
  • Gemini API
  • Blender
詳しく見る
課題
日記は続かない。毎日必ずある歯みがきの時間なら記録を習慣にできる。
機能
過去の回答と比べて普段と違うときだけ追加の質問をする。分析は端末内で行い、記録は外部に送らない。
AI
求めたときだけGemini APIを呼ぶ。APIキーはサーバーレス関数で中継して秘匿。
デバイス
本番用の専用デバイスをBlenderでモデリング。現在はWeb版で検証中。
