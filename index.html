サークル練習管理Webアプリ (Next.js, TypeScript, Supabase, Vercel)

Problem

約150名・9ジャンルのダンスサークルでは、練習室の予約結果をExcelで時間割にし、画像にしてLINEで共有していました。各自が手でカレンダーに登録し、空き部屋の使用はLINEのコメントで宣言、出欠は個別に確認。情報がLINE・Discord・紙に分散し、見落としが起きていました。

Solution

練習日程・空き部屋の申請・出欠・鍵の受け渡しを一つのWebアプリにまとめました。

  • 練習室×時間の時間割と、自分の予定だけを集めたマイカレンダー
  • 空き部屋を10分単位で申請（重複はデータベース側の制約でも防止）
  • 出欠のワンタップ回答、鍵の所持者と施錠状況の共有、プッシュ通知
  • GoogleやAppleのカレンダーへの自動反映（購読URL）
  • 役職ごとの権限（Supabase RLS）、卒業生アカウントへの移行

開発にはAIエージェント（Claude Code）を活用し、私は仕様書の作成・設計判断・動作確認・メンバーの声を受けた改善を担っています。仕様書は改訂を重ね、v1.29まで更新しています。

Result

2026年9月に運用を始め、約2か月でメンバーのほぼ全員が週3〜4日使う状態になりました。出欠確認の手間はほぼゼロになっています。現在は、画面の分かりやすさとiOSで通知が届かない問題の改善に取り組んでいます。

Swift, SwiftUI, Homebrew

Denko (Swift, SwiftUI, Homebrew)

Overview

Macのメニューバーを駅の電光掲示板のように使えるアプリ。天気・ニュース・電車の遅延・地震や津波の情報、Claude CodeやCodexなどのコーディングエージェントの完了通知、CPU・メモリの使用率を、流れる文字で知らせます。

Why

作業中に複数のアプリや通知を見に行くと集中が切れることが不満でした。視界の端に一行だけ必要な情報が流れる形にすれば、作業を止めずに状況をつかめると考えて作りました。

What I built
  • 気象庁XML・Open-Meteo・公共交通オープンデータなど複数の公開データを取得し、一つの表示に統合
  • AIエージェントの作業完了・利用量をメニューバーで確認できる仕組み
  • Releases（DMG）とHomebrew caskでの配布（brew install --cask oriharu-heaven/tap/denko）
  • データは端末内で処理し、トラッキングなし。MITライセンスで公開（現在ベータ版）

Overview

Why

What I built

BOOMTECT (Unity, C#)

Overview

学校や職場といった身近な環境を舞台に、特殊な爆発物を用いて建物を破壊する爽快破壊シミュレーションゲーム。

Motivation

日々のちょっとした退屈やモヤモヤを、ゲームの中でスカッと吹き飛ばしてもらいたい！という思いから企画しました。クスッと笑えるようなユーモアと、本格的なパズル要素を掛け合わせ、多くの人に楽しんでもらえる作品を目指しました。

Challenges

単に壊すだけでなく、ゲーム性を高めるための物理演算とパフォーマンスの両立に挑戦しました。ゲーム内の様々なアクションを実装するため、C#でのコンポーネント設計を工夫しています。大量の破片オブジェクトが発生した際も快適にプレイできるよう、不要な演算の削減やオブジェクトの管理手法を実装した点が一番の工夫です。
