サークル練習管理Webアプリ (TypeScript, AIエージェント活用)

Problem

約150名のダンスサークルで、日程調整・メンバーの状況管理・出欠連絡がLINE・Discord・紙に分散していました。連絡事項は手打ちで、出欠は個別に確認が必要だったため、見落としが起きていました。

Solution

予定・出欠・連絡を一つのWebアプリにまとめました。開発にはAIエージェントを活用し、設計と動作確認、メンバーの声を聞いての改善に力を注いでいます。

Result

2026年9月に運用を始め、約2か月でメンバーのほぼ全員が週3〜4日使う状態になりました。出欠確認の手間はほぼゼロになっています。現在は、画面の分かりやすさとiOSで通知が届かない問題の改善に取り組んでいます。

BOOMTECT (Unity, C#)

Overview

学校や職場といった身近な環境を舞台に、特殊な爆発物を用いて建物を破壊する爽快破壊シミュレーションゲーム。

Motivation

日々のちょっとした退屈やモヤモヤを、ゲームの中でスカッと吹き飛ばしてもらいたい！という思いから企画しました。クスッと笑えるようなユーモアと、本格的なパズル要素を掛け合わせ、多くの人に楽しんでもらえる作品を目指しました。

Challenges

単に壊すだけでなく、ゲーム性を高めるための物理演算とパフォーマンスの両立に挑戦しました。ゲーム内の様々なアクションを実装するため、C#でのコンポーネント設計を工夫しています。大量の破片オブジェクトが発生した際も快適にプレイできるよう、不要な演算の削減やオブジェクトの管理手法を実装した点が一番の工夫です。

Portfolio Site (HTML, CSS, GSAP, Three.js)

Overview

自身のスキルや経験、制作物を紹介するためのポートフォリオサイト。

Motivation
