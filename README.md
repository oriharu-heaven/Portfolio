## Works

- **サークル練習管理アプリ**（Next.js, TypeScript, Supabase）: 約150名のサークルの練習日程・空き部屋申請・出欠をまとめたWebアプリ。先輩が立ち上げ2026年9月から運用中。2026年10月に開発を引き継ぎ、大幅に改良。
- **らしさの村**（Unity, C#, WebGL）: 全国メンターハッカソン2026で最優秀賞。「らしさ」を押し付けられる村で本当になりたい自分へ変わっていく3Dゲーム。5人チームでPMとメインプログラマーを担当。[遊ぶ](https://menter-hackathon.github.io/team5/) / [GitHub](https://github.com/menter-Hackathon/team5)
- **hachioji-gov**（TypeScript, React, Cloud Run, Firebase）: GDGoC ハッカソンのチーム作品。子育て世帯向けの医療・福祉・子育て情報ナビ（PWA）。Reactのフロントエンドを中心に担当。
- **Denko**（Swift, SwiftUI）: メニューバーを駅の電光掲示板にするMacアプリ。Homebrewで配布。
- **ミガキ殿**（TypeScript, React, Gemini API）: 歯みがきの時間に気分・体調を記録するPWA。
- **banjirun**（Unity, C#, OpenXR, Blender）: 個人で制作中のゲーム（VR / PC）。
- **BOOMTECT**（Unity, C#）: 物理演算の破壊パズルゲーム。[unityroom](https://unityroom.com/games/boomtect)で公開。
- **Langairy**（Swift, SwiftUI）: 英語学習用のiOSアプリ。[App Store](https://apps.apple.com/jp/app/langairy/id6760103888)で公開。
