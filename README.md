# Haru Orishimo Portfolio

東京都立大学 システムデザイン学部 情報科学科2年、折下陽春のポートフォリオサイトです。
https://oriharu-heaven.github.io/Portfolio/

> 現在、Vite + TypeScript + WebGL で作り直し中です。作り直しの過程は [docs/textbook/](docs/textbook/README.md) に教科書としてまとめています。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + dist/ にビルド
npm run preview  # ビルド結果を確認
```

main に push すると GitHub Actions がビルドし、GitHub Pages に公開します。
